# TrejoTech

Sitio personal hecho con React y Vite.

## Iniciar en Mac

1. Descomprime el archivo y abre la carpeta `trejotech-vite` en VS Code.
2. Abre la terminal de VS Code y ejecuta:

```bash
npm install
npm run dev
```

3. Abre la dirección local que aparezca en la terminal (normalmente http://localhost:5173).

## Archivos principales

- `src/App.jsx`: contenido, secciones y enlace a la herramienta de bitácoras.
- `src/index.css`: colores y diseño adaptable al teléfono.
- `index.html`: título y descripción del navegador.

Para verificar la versión final: `npm run build`.

Esta carpeta es una copia editable. Los cambios que hagas en tu Mac no modifican automáticamente la página publicada.
